Logistic Management System

Automated Distance Matrix and Cost Routing Framework in Java

Designed and implemented a modular, menu-driven delivery tracking application in Java, engineered to dynamically manage physical route variations, calculate multi-variable operational parameters, and handle strict validation profiles across diverse vehicular options[cite: 1].

About This Project

The project focused on building an interactive core matrix to evaluate supply chain distribution states[cite: 1]. The system handles city nodes and symmetric distances between them using an optimized 2D array matrix[cite: 1]. It allows users to actively manage transit paths through dynamic options to add, rename, and shift city records up to a designated cap of thirty unique locations[cite: 1]. Furthermore, the program features comprehensive operational mathematical modules to compute estimated delivery times, fuel usage parameters, profit curves, and total customer costs before saving operational records securely[cite: 1].

Key Highlights

  • Dynamic Symmetrical Array Matrices: Formulated structured tracking matrices to securely process distance estimations and track city node connections smoothly within flat memory spaces[cite: 1].
  • Capacity Verification Engineering: Integrated strict validation safety logic filters to crosscheck shipment mass inputs against custom vehicle thresholds (Three-Wheel, Van, Lorry) prior to permitting transit updates[cite: 1].
  • Automated Data Persistence: Deployed robust text file input/output handling structures to automatically store, update, and serialize system routing grids and histories between separate execution sessions (routes.txt and deliveries.txt)[cite: 1].
  • Multi-Variable Cost Processing: Programmed multi-tier tracking equations that compute dynamic logistics criteria, including fuel consumption, baseline expenses, and exact profit margins across paths[cite: 1].
  • Comprehensive Performance Engine: Developed automated reporting features to dynamically generate analytical summaries tracking global metrics like absolute distance, revenue, average time, and route records[cite: 1].
